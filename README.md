# Pocket · AI 会话遥控台

把电脑里 Claude Code / Codex 的会话搬到手机上:看它跑到哪了、看它生成的图和文件、一句话派下一个活,该拍板的时候替你按键。

官网:<https://pocket.pocketcli.net/>

## 下载

| 平台 | 安装包 | 说明 |
|---|---|---|
| Android | [Pocket.apk](https://github.com/ltsqyg-lab/pocket-releases/releases/latest/download/Pocket.apk) | 安装时允许「未知来源」;测试签名,新版直接覆盖安装 |
| iOS | [Pocket-unsigned.ipa](https://github.com/ltsqyg-lab/pocket-releases/releases/latest/download/Pocket-unsigned.ipa) | 未签名,需 AltStore / Sideloadly 自签,或用 Xcode 装到自己的设备 |

以上链接始终指向最新版本。历史版本与每个文件的 sha256 见 [Releases](https://github.com/ltsqyg-lab/pocket-releases/releases)。

## 怎么用

1. 在跑 Claude Code / Codex 的电脑上装桌面端(Mac 的 .pkg 或 Windows 的 .exe),在菜单栏/托盘里登录账号。
2. 手机装 App,用同一个账号登录,电脑上的会话就出现在列表里。

内测期注册需要邀请码。
